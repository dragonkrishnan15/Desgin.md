# UI Style Field Guide Catalog (28 Styles)

### Clean & Structured
1. **01 Minimalism** (`01-minimalism.json`)
   - *Tagline*: Say more with less.
   - *Palette*: `#FAFAF8`, `#111111`, `#8A8A85`, `#E6E4DF`, `#C9A27E`
   - *Typefaces*: Inter, Helvetica Now, Neue Montreal
   - *Best For*: Premium products, portfolios, studios, single-product launches.
